# Mini RPG

Кооперативная RPG в процедурном мире: горы, реки, руины со скелетами. Играть можно одному или с друзьями (до 4 игроков).

## Как установить
1. Открой раздел **[Releases](../../releases/latest)** и скачай архив `MiniRPG_<версия>.zip`.
2. Распакуй в любую папку, где у тебя есть права на запись, например `D:\Games\MiniRPG`.
   Не распаковывай в `Program Files`: оттуда игра не сможет сама обновляться.
3. Запусти `MiniRPG.exe`.

## Обновления
Игра обновляется сама: при запуске лаунчер проверяет файлы и предлагает установить новую версию, если она вышла.

## Игра с друзьями
- Один игрок нажимает **«Создать сервер»**. Его IP показан в меню паузы (Esc).
- Остальные нажимают **«Подключиться»** и вводят этот IP.
- В одной домашней сети подойдёт IP из меню паузы. Через интернет удобнее всего Radmin VPN или Hamachi, либо проброс порта **7777 UDP** на роутере.
- У всех игроков должна быть одинаковая версия игры.
